# 数取器（カチカチカウンター）

交通量調査などで使う数取器をブラウザで再現したツールです。
大きな ＋ ボタンをタップしてカウントし、1分あたりのペースと1分ごとのグラフを表示します。

https://daaaaaai.github.io/tally_counter/

## 機能

- **＋ボタン** — タップした瞬間に反応（スペース / Enter / ↑ キーでも可）
- **平均ペース** — 最初のタップから最後のタップまでの間隔から算出した1分あたりの回数
- **直近ペース** — 直近10回の間隔から算出した1分あたりの回数
- **グラフ** — 最初のタップを起点に1分ごとのカウントを棒グラフで表示（進行中の分は薄い色）
- **−1** — 直前の1回を取り消し（Backspace / − キーでも可）
- **CSV** — 各タップの時刻と経過秒をダウンロード
- **自動保存** — 誤ってページを閉じても、同じブラウザで開き直せば続きから再開

## 使い方

```
index.html をブラウザで開くだけ
```

ビルド・インストール不要です。データはブラウザ内（localStorage）にのみ保存され、サーバーには送信されません。
